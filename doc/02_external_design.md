# 2. 外部設計書

## 2.1. 概要

本ドキュメントは、シフト管理アプリケーションの外部設計を定義する。
主にCUI（キャラクターユーザーインターフェース）の画面構成と操作フローについて記述する。

## 2.2. 画面遷移

アプリケーションは、以下の画面で構成される。

```
+----------------+
|   メインメニュー   |
+----------------+
| 1. 社員管理    |
| 2. シフト管理    |
| 3. 終了        |
+----------------+
      |
      |--- 1. 社員管理 ---> +------------------+
      |                    |    社員管理メニュー    |
      |                    +------------------+
      |                    | 1. 社員を登録する    |
      |                    | 2. 社員一覧を表示する  |
      |                    | 3. メインメニューに戻る |
      |                    +------------------+
      |
      |--- 2. シフト管理 ---> +------------------+
                           |    シフト管理メニュー    |
                           +------------------+
                           | 1. シフトを作成・編集する |
                           | 2. シフトを表示する    |
                           | 3. メインメニューに戻る |
                           +------------------+
```

## 2.3. 画面レイアウト

### 2.3.1. メインメニュー

アプリケーション起動時に表示される。

```
--- シフト管理アプリケーション ---
1. 社員管理
2. シフト管理
3. 終了
操作を選択してください: _
```

### 2.3.2. 社員管理メニュー

メインメニューで「1」を選択すると表示される。

```
--- 社員管理 ---
1. 社員を登録する
2. 社員一覧を表示する
3. メインメニューに戻る
操作を選択してください: _
```

#### 2.3.2.1. 社員登録

「1. 社員を登録する」を選択した場合。

```
新しい社員の氏名を入力してください: [山田 太郎]
山田 太郎さんを登録しました。
```

#### 2.3.2.2. 社員一覧

「2. 社員一覧を表示する」を選択した場合。

```
--- 登録社員一覧 ---
- 鈴木 一郎
- 佐藤 花子
- 山田 太郎
```

### 2.3.3. シフト管理メニュー

メインメニューで「2」を選択すると表示される。

```
--- シフト管理 ---
1. シフトを作成・編集する
2. シフトを表示する
3. メインメニューに戻る
操作を選択してください: _
```

#### 2.3.3.1. シフト作成・編集

「1. シフトを作成・編集する」を選択した場合。

```
シフトを編集する年月を入力してください (例: 202304): [202304]
日付を選択してください (1-31): [1]
シフトを選択してください (1: 早番, 2: 遅番): [1]
担当する社員を選択してください:
1. 鈴木 一郎
2. 佐藤 花子
社員番号を選択してください: [1]
2023年4月1日の早番に鈴木 一郎さんを割り当てました。
```

#### 2.3.3.2. シフト表示

「2. シフトを表示する」を選択した場合。

```
表示する年月を入力してください (例: 202304): [202304]

--- 2023年4月 シフト表 ---
日付 | 早番       | 遅番
----------------------------------
 1   | 鈴木 一郎   | 佐藤 花子
 2   | (未割り当て) | 鈴木 一郎
...
30   | 山田 太郎   | (未割り当て)
```
