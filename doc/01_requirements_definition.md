# 1. 要件定義書

## 1.1. 概要

本ドキュメントは、シフト管理アプリケーションの要件を定義する。
このアプリケーションは、従業員のシフトを効率的に管理することを目的とし、CUI（キャラクターユーザーインターフェース）で操作できるものとする。

## 1.2. 機能要件

### 1.2.1. 社員管理機能

- **社員の登録**: 新しい社員の氏名を登録できる。
- **社員の一覧表示**: 登録されている全社員の氏名を表示できる。

### 1.2.2. シフト管理機能

- **シフトの作成**: 特定の年月のカレンダーを生成し、各日付に対して早番または遅番のシフトを割り当てることができる。
- **シフトの割り当て**: 日付とシフト（早番/遅番）を指定し、担当する社員を割り当てることができる。
- **シフトの表示**: 指定した年月のシフト表（カレンダー形式）を表示できる。誰がどのシフトに入っているかがわかるようにする。

## 1.3. 非機能要件

- **プラットフォーム**: Python 3.x 環境で動作すること。
- **永続化**: 登録した社員情報とシフト情報は、アプリケーションを終了しても保持されること（ファイル保存など）。
- **操作性**: CUIで直感的に操作できるメニューを提供すること。
- **コード品質**: オブジェクト指向設計に基づき、適切なクラスと責務の分離を行うこと。また、可読性の高いコードとdocstringを記述すること。
